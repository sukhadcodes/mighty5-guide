Save this for offline use

The whole guide is one small self-contained site — once it's loaded once, it keeps working with no signal at all.

1

While you still have wifi or signal, open this site once on your phone and let it fully load. It quietly caches every page in the background — watch for the “Saved for offline” badge at the top.

2

Optional but recommended: tap your browser's share/menu button and choose “Add to Home Screen.” It'll open like a regular app icon, still fully offline.

3

In the parks, open it from your home screen or bookmarks — no data connection needed. Revisit on wifi occasionally to pick up any future edits.

Host it for free

This is a fully static site (just HTML/CSS/JS), so any free static host works. GitHub Pages is the simplest if you don't have a preference:

1

Create a free GitHub account, then a new repository named anything, e.g. mighty5-guide.

2

Upload every file from this folder (drag-and-drop works on github.com → “Add file” → “Upload files”).

3

Go to Settings → Pages, set the source to the main branch, root folder, and save.

4

Your site is live in a minute or two at https://yourusername.github.io/mighty5-guide — share that link or open it on your phone.
